# Asistente para Android · beta pública

Un asistente personal con memoria local, chat por texto y audio, agenda, pendientes, conexiones y backup cifrado en Drive.

[Conocer el proyecto y descargar](https://asistente-android-marotte.miniapricot1.chatgpt.site) · [Versiones](https://github.com/marottejm/asistente-android/releases)

Este repositorio distribuye los APK de la beta. No contiene el código fuente Android, los datos del desarrollador ni claves de API o de firma.

## Antes de instalar

- Android 9 o posterior. Validación principal de la app en Pixel 9 emulado con Android 17.
- Clave propia de OpenAI para las funciones de IA; el uso de la API se cobra en la cuenta del proveedor.
- Los conectores de Google están en modo de prueba para las cuentas autorizadas.
- La sincronización continua entre dispositivos aún no está implementada. Puede restaurarse un backup de Drive usando su frase de recuperación.
- Desde la versión 0.31.0 podés buscar, descargar y verificar las versiones públicas en Ajustes → Actualizaciones, sin token de GitHub.

Descargá el APK desde Releases y abrilo en Android. No desinstales la versión anterior para actualizar. Android puede pedirte habilitar instalaciones desde el navegador. La beta 0.31.0 usa una firma de distribución vinculada a la de la beta 0.30.0. Para pasar de la beta pública anterior, abrí el APK sobre la instalación existente.

Para reportar errores, usá Issues sin incluir claves, frases de recuperación, datos de salud ni conversaciones privadas. «Asistente» es el nombre provisional del proyecto.
